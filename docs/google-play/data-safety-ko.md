# Google Play Data Safety 입력 초안

작성 기준: 2026-07-28 코드와 개인정보처리방침 초안. Play Console에 제출하기 전 아래 `확정 필요` 항목을 먼저 해결한다.

## 데이터 수집 및 보안

- 앱이 필수 사용자 데이터 유형을 수집하거나 공유하는가: **예**
- 전송 중 암호화되는가: **예** — 앱·백엔드·클라우드 간 HTTPS/TLS 사용을 배포 환경에서 최종 확인
- 사용자가 데이터 삭제를 요청할 수 있는가: **예**
- 삭제 요청 URL: `https://app.happydoctor.kr/delete-data`
- 계정 생성 기능: **없음**. 상담별 비밀 상태 토큰을 사용한다.
- 데이터가 일시적으로만 처리되는가: **아니요**

## 선택할 데이터 유형

| Play 데이터 유형 | 수집 | 공유 | 필수 여부 | 사용 목적 |
|---|---:|---:|---|---|
| 개인정보 > 전화번호 | 예 | 아니요* | 선택 | 의료진 답변 알림, 앱 기능 |
| 개인정보 > 기타 정보 | 예 | 아니요* | 일부 선택 | 나이·연령대, 성별, 언어, 상담 접수·검토·답변 |
| 개인정보 > 사용자 ID | 예 | 아니요* | 필수 | 상담 식별자·상태 토큰으로 상태 조회와 보안 유지 |
| 건강 및 피트니스 > 건강 정보 | 예 | 아니요* | 필수 | 증상·발생 시점·점수·병력·복용약을 의료진이 검토하고 답변 |
| 메시지 > 기타 인앱 메시지 | 예 | 아니요* | 필수 | 상담 본문·후속 질문·의료진 답변 제공 |
| 사진 및 동영상 > 사진 | 예 | 아니요* | 선택 | 이용자가 선택한 상담 사진을 의료진이 검토 |
| 기기 또는 기타 ID | 예 | 아니요* | 필수 | IP·브라우저/기기 관련 보안 로그, 부정 사용 방지와 서비스 보안 |

각 유형의 처리 방식은 다음과 같이 답한다.

- 수집됨: **예**
- 공유됨: **아니요***
- 데이터가 일시적으로 처리됨: **아니요**
- 사용자가 수집 여부를 선택할 수 있음: 전화번호·사진은 **예**, 나머지 핵심 상담 정보와 보안 식별자는 **아니요**
- 목적: **앱 기능**, 보안 식별자·로그에는 **사기 방지, 보안 및 규정 준수**도 선택
- 광고 또는 마케팅, 분석, 맞춤설정, 계정 관리: **선택하지 않음**

## 현재 선택하지 않을 유형

- 위치, 연락처, 이메일 주소, 이름, 주소, 금융 정보, 오디오, 파일·문서, 캘린더
- 앱 활동/광고 데이터와 웹 탐색 기록
- Health Connect 데이터
- 광고 ID

코드나 배포 서비스 설정이 바뀌어 위 데이터가 서버로 전송되면 선언도 함께 갱신한다.

## 확정 필요 — 제출 차단 항목

1. `공유 안 함`은 자원봉사 의료진이 단체의 승인된 인력으로서 단체 지시에 따라 처리하고, 비밀유지·개인정보 처리 의무와 접근통제가 문서화된 경우를 전제로 한다. 의료진이 독립된 제3자로 판단되면 전화번호를 제외한 실제 열람 데이터(건강정보, 메시지, 사진, 기타 개인정보 등)를 **공유됨**으로 다시 선언해야 한다.
2. Firebase/Google Cloud, Render, Vercel, SOLAPI의 실제 계약 주체·처리 리전·보유기간을 확인하고 개인정보처리방침의 국외 처리 내용을 확정한다.
3. 서버·CDN 로그에 IP 외 다른 식별자나 진단 데이터가 저장되는지 운영 설정에서 확인한다.
4. 상담기록에 법정 보존 의무가 적용되는지 확인한다. 적용된다면 삭제요청 화면과 실제 삭제 로직을 법정 보존 예외와 일치시킨다.
5. Play Console 미리보기와 실제 앱의 개인정보처리방침·삭제 동작이 동일한지 마지막으로 대조한다.

Google 안내: 내부 테스트만 단독으로 활성화된 앱은 Data Safety 표시 의무에서 예외일 수 있지만, 폐쇄·공개·프로덕션 트랙으로 확대하기 전에 정확한 양식을 제출해야 한다.
